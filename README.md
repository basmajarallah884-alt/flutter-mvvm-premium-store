## 🇺🇸 Project Overview (English)

This is a personal project developed to practice building scalable and well-structured mobile applications using **Flutter**. The main goal was to implement industry-standard design patterns and handle real-world data scenarios.

### �️ Architecture & Implementation
- **Architecture**: **MVVM (Model-View-ViewModel)** was chosen to ensure a clean separation between the UI and business logic.
- **State Management**: Implemented using the **Provider** package for efficient and reactive UI updates.
- **Networking**: Used **Dio** to fetch data from the [DummyJSON](https://dummyjson.com) REST API.
- **Local Persistence**: Leveraged **Sqflite** for cart management and **Shared Preferences** for storing user sessions.

### 🚀 Key Features
- **Dynamic Catalog**: Fetching and displaying products by category from a live API.
- **Persisted Cart**: A fully functional shopping cart that saves items to a local SQLite database.
- **User Authentication**: Integrated login flow with session handling.
- **Clean UI**: Developed with a focus on responsiveness and user experience.

## 🇸🇦 نظرة عامة على المشروع (العربية)

مشروع شخصي يهدف إلى تطبيق أساسيات تطوير تطبيقات الهاتف المحمول باستخدام **Flutter**، مع التركيز على كتابة كود منظم يتبع المعايير البرمجية الحديثة.

### 🏗️ البناء البرمجي والتقنيات
- **نمط التصميم**: تم اعتماد نمط **MVVM** لضمان فصل منطق العمل عن واجهات المستخدم، مما يسهل عملية التطوير والصيانة.
- **إدارة الحالة**: استخدام حزمة **Provider** لإدارة بيانات التطبيق بشكل تفاعلي وسلس.
- **التعامل مع البيانات**: الربط مع واجهة برمجية (API) خارجية باستخدام حزمة **Dio** لجلب المنتجات والتصنيفات.
- **قاعدة البيانات المحلية**: استخدام **SQLite** لحفظ بيانات السلة لضمان بقائها حتى بعد إغلاق التطبيق.

### 🌟 المميزات الرئيسية
- **كتالوج منتجات تفاعلي**: عرض المنتجات وتصنيفها بناءً على البيانات القادمة من السيرفر.
- **نظام السلة**: إضافة المنتجات إلى السلة وحفظها محلياً باستخدام قاعدة بيانات مدمجة.
- **تسجيل الدخول**: محاكاة عملية تسجيل دخول المستخدم وإدارة الجلسة.
- **تصميم متجاوب**: واجهة برمجية حديثة تدعم مختلف أحجام الشاشات.
